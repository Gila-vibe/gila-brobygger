# Accessibility baseline

- Semantic landmarks: header, nav, main, sections and footer.
- Skip link to main content.
- Keyboard-visible focus indicators.
- Mobile menu exposes `aria-expanded` and `aria-controls`.
- Respect `prefers-reduced-motion`.
- Use meaningful link text and heading order.
- Ensure text and interactive controls have sufficient contrast and touch size.
- Any future informative images require useful alternative text; decorative images should use empty alt text.
- Test with keyboard and a screen reader before production release.

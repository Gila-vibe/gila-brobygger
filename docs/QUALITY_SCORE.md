# Quality scorecard

Score each item 0 (missing), 1 (partial), or 2 (verified).

| Area | Score | Evidence |
|---|---:|---|
| Content accuracy |  | Owner-approved copy |
| Contact links |  | Recipient and subject checked |
| Responsive layout |  | Desktop/tablet/mobile |
| Accessibility |  | Keyboard and screen-reader checks |
| SEO basics |  | Titles, descriptions, headings |
| Security/privacy |  | Data-flow and third-party review |
| Automated checks |  | Script/CI result |
| Production readiness |  | HTTPS, backup, deployment review |

Do not use the score as a substitute for legal, privacy or security review. Record unverified items explicitly.

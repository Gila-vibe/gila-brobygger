# SEO checklist

- Keep a unique, descriptive title and meta description on each page.
- Use one clear H1 per page and a logical heading hierarchy.
- Keep Danish copy specific and useful; avoid keyword stuffing.
- Add verified canonical URLs after the final domain and URL structure are confirmed.
- Create and validate `sitemap.xml` and `robots.txt` before launch.
- Add Open Graph metadata and social preview image after approved brand assets are available.
- Connect Google Search Console only with owner approval.
- Do not promise rankings or add unsupported structured data.
